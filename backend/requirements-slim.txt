# Slim dependency set for free-tier cloud deploy (Render / Fly / Cloud Run).
#
# Identical to requirements.txt EXCEPT the multi-GB ML stack is removed:
#   torch, sentence-transformers, FlagEmbedding, transformers, faiss-cpu,
#   easyocr, langchain, langchain-community
#
# This is safe because every one of those is imported lazily or not at all:
#   * app/rag/embeddings.py only imports sentence_transformers when
#     IPSAKTI_USE_BGE_M3 != "0", and otherwise falls through to the local
#     hashing embedder (192-dim).
#   * app/rag/reranker.py only loads a model when IPSAKTI_USE_RERANKER != "0".
#   * app/rag/faiss_retriever.py imports faiss only inside methods, and its
#     annotations are never evaluated at runtime.
#   * easyocr is imported inside one function in app/services/fetchers.py.
#   * langchain / langchain-community have no import sites in app/.
#
# Deploy with IPSAKTI_USE_BGE_M3=0 and IPSAKTI_USE_RERANKER=0 so the app
# stays on the hashing + BM25 path and never needs the model download.
